# Employee Learning Portal
This learning portal is designed to provide employees with access to various courses for professional development.

## Functionality
1.  User Authentication:
    * Register, login, and logout functionality.
2.  Course Catalog:
    * View available courses to enroll in.
3.  Enrollment Management:
    * View enrolled courses.
    * Show enrollment availability for courses with limited capacity.
    * Employees can enroll and drop courses.
4.  Profile Management:
    * Employees can view and edit their profile settings.
